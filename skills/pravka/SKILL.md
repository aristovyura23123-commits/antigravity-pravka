# Pravka — Профессиональная редактура, защита инвариантов и очистка текстов

**Pravka** — это плагин для Antigravity CLI, созданный для бескомпромиссной вычитки, очеловечивания и проверки текстов на русском языке. Он сочетает надёжные детерминированные алгоритмы (офлайн-проверка кодовых точек Unicode, удаление скрытого мусора, строгая защита фактов) и продвинутую редакторскую работу без бюрократизма и пустых ИИ-клише.

---

## 🛠 Доступные утилиты плагина

В плагине предустановлен локальный исполняемый скрипт:
`scripts/pravka_cli.py`

### Команды CLI:
1. **Анализ текста (Unicode, стиль, защищённые данные):**
   ```bash
   python3 scripts/pravka_cli.py analyze input.txt
   ```
2. **Детерминированная очистка (удаление скрытых знаков, нормализация пробелов, омоглифы):**
   ```bash
   python3 scripts/pravka_cli.py clean input.txt -o cleaned.txt --spaces --confusables --style
   ```
3. **Просмотр защищённых инвариантов:**
   ```bash
   python3 scripts/pravka_cli.py protect input.txt
   ```
4. **Строгая верификация результата (проверка сохранности чисел и ссылок):**
   ```bash
   python3 scripts/pravka_cli.py verify original.txt rewritten.txt
   ```
5. **Сравнение diff с проверкой оговорок и отрицаний:**
   ```bash
   python3 scripts/pravka_cli.py diff original.txt rewritten.txt
   ```

## 📋 Рабочий процесс редактуры (Workflow)

Когда пользователь передаёт текст или файл для обработки:

### Этап 1. Предварительная очистка и анализ инвариантов
1. Проверьте исходный текст на скрытые знаки (zero-width spaces `\u200b`, word joiner `\u2060`, BOM `\ufeff`, bidi-переопределения `\u202a`..`\u202e`).
2. Проверьте наличие смешанной раскладки (латинские омоглифы внутри кириллических слов).
3. Извлеките защищённые инварианты (числа с единицами, ссылки, код, цитаты).

### Этап 2. Определение формата и глубины редактуры
- **Жанр текста:**
  - `post` — пост для Telegram/соцсетей, живой авторский слог, динамичный ритм.
  - `plain` / `educational` — статья, блог, обучающий материал, простое и понятное объяснение.
  - `business` — деловое письмо, регламент, коммерческое предложение, уважительный и точный тон.
  - `academic` — научный или аналитический текст, высокая точность терминов.
- **Глубина правки:**
  - **Light (Лёгкая правка):** устранение канцелярита, удаление пустых подводок, исправление согласования, разделение чрезмерно длинных предложений. Порядок абзацев сохраняется.
  - **Rephrase (Глубокое перефразирование):** полное переосмысление композиции и синтаксиса, извлечение тезисов и фактов с последующим написанием живым языком с нуля.

### Этап 3. Редактура по стандартам Pravka

#### Инварианты (НЕ ИЗМЕНЯТЬ):
- Числа, суммы, проценты, даты, объёмы (`100 мл`, `2 300 руб`, `15%`, `12 мая`).
- URL-адреса, Markdown-ссылки `[текст](url)`, блоки кода.
- Прямые цитаты в кавычках.
- Оговорки степени уверенности («обычно», «примерно», «возможно», «не установлено») и условия.
- Отрицания («не», «нет», «ни», «нельзя»).

#### Что безжалостно устранять:
- **Пустые преамбулы:** *«Важно отметить, что»*, *«Следует подчеркнуть, что»*, *«Необходимо учитывать, что»* → начинайте сразу с предмета и действия.
- **Расщеплённые сказуемые:**
  - *«осуществляет проверку»* → *«проверяет»* (или *«проводит проверку»*).
  - *«осуществляет обработку»* → *«обрабатывает»*.
  - *«производит расчёт»* → *«рассчитывает»*.
  - *«оказывает помощь»* → *«помогает»*.
- **Пустые штампы:** *«в современном мире»*, *«в сегодняшних реалиях»*, *«является неотъемлемой частью»*, *«играет ключевую роль»*.
- **Многословие:** *«на данный момент времени»* → *«сейчас»*, *«для того, чтобы»* → *«чтобы»*, *«имеет возможность сделать»* → *«может сделать»*.
- **Искусственные концовки:** *«Подводя итог, можно сказать...»*, *«Таким образом, подводя черту...»*. Финал должен содержать реальную мысль текста.

### Этап 4. Верификация и отчёт
1. Сверьте получившийся текст с оригиналом (используйте команду `verify`).
2. Предоставьте пользователю:
   * Отредактированный текст.
   * Краткую сводку выполненных улучшений.
   * Подтверждение сохранности всех фактов, чисел и ссылок.
