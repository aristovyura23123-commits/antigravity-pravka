# Pravka — Плагин для Antigravity CLI

**Pravka** — плагин для среды **Antigravity CLI**, предназначенный для глубокой ИИ-редактуры, вычитки, очеловечивания (гуманизации) русскоязычных текстов, удаления канцелярита и ИИ-штампов, а также офлайн-очистки от скрытых знаков Unicode.

Плагин разработан на основе лучших практик проекта [Shelter-Humanizer](https://github.com/IT-Shelter-Labs/Shelter-Humanizer) и адаптирован для бесшовной интеграции с агентными рабочими процессами Antigravity.

---

## Ключевые возможности

1. **Офлайн-очистка и проверка Unicode:**
   - Поиск и удаление пробелов нулевой ширины (`\u200b`, `\u2060`, `\ufeff`), мягких переносов (`\u00ad`), управляющих символов и bidi-переопределений (`\u202a`–`\u202e`).
   - Автоматическая детекция латинских омоглифов внутри русских слов (подмена букв `c`, `a`, `e`, `o`, `p`, `x`).
   - Нормализация типографических пробелов и приведение к канонической форме Unicode NFC.

2. **Строгая защита инвариантов (Data Protection):**
   - Гарантированное сохранение чисел, процентов, сумм и единиц измерения (`100 мл`, `2 300 руб`, `15%`).
   - Сохранение ссылок (`https://...`, `[текст](url)`), блоков кода (`` `...` ``, ```` ```...``` ````) и цитат.
   - Защита модальных оговорок («обычно», «примерно», «возможно») и отрицаний («не», «нет», «ни», «нельзя»).

3. **Стилистическая редактура без канцелярита:**
   - Устранение пустых вводных конструкций (*«Важно отметить, что»*, *«Следует подчеркнуть, что»*).
   - Замена отглагольных существительных и расщепленных сказуемых на активные глаголы (*«осуществляет проверку»* → *«проверяет»*).
   - Устранение банальных ИИ-штампов (*«В современном мире»*, *«Играет ключевую роль»*, *«Подводя итог»*).

4. **Два режима работы:**
   - **Агентный навык в Antigravity CLI** (`skills/pravka`): автоматическая активация по запросу пользователя в чате.
   - **Автономный CLI-инструмент** (`scripts/pravka_cli.py`): работает напрямую в терминале, без внешних зависимостей (только стандартная библиотека Python).

## Установка плагина в Antigravity CLI

### Способ 1. Глобальная установка (для всех проектов)
Скопируйте репозиторий в каталог плагинов Antigravity:
```bash
git clone https://github.com/aristovyura23123-commits/antigravity-pravka.git ~/.gemini/config/plugins/pravka
```

### Способ 2. Локальная установка в проект
Скопируйте репозиторий в `.agents/plugins/` вашего проекта:
```bash
mkdir -p .agents/plugins
git clone https://github.com/aristovyura23123-commits/antigravity-pravka.git .agents/plugins/pravka
```

После этого плагин будет автоматически обнаружен Antigravity CLI.

## Использование через чат Antigravity CLI

Вы можете обращаться к агенту на естественном языке:
- *«Правка: гуманизируй этот текст, убери канцелярит и штампы»*
- *«Проверь файл post.txt на скрытые символы и омоглифы»*
- *«Перефразируй описание товара, сохранив все цены, объёмы и ссылки»*
- *«Выполни вычитку статьи по правилам Pravka»*

---

## Использование через консоль (CLI)

Скрипт не требует сторонних пакетов:

```bash
# 1. Анализ текста (Unicode, стиль, защищённые данные)
python3 scripts/pravka_cli.py analyze input.txt

# 2. Очистка невидимых символов и базовых клише
python3 scripts/pravka_cli.py clean input.txt -o cleaned.txt --confusables --style

# 3. Список защищаемых инвариантов
python3 scripts/pravka_cli.py protect input.txt

# 4. Проверка сохранности чисел и инвариантов между оригиналом и черновиком
python3 scripts/pravka_cli.py verify original.txt rewritten.txt

# 5. Сравнение текстов (diff) с анализом изменения оговорок и отрицаний
python3 scripts/pravka_cli.py diff original.txt rewritten.txt
```
